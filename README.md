# taskFy

Gerenciador de tarefas desenvolvido com **HTML**, **CSS** e **JavaScript** puro.  
O projeto tem como foco praticar fundamentos do front-end, organização de código e persistência de dados no navegador.

## Funcionalidades
- Adicionar e remover tarefas
- Marcar/desmarcar como concluída
- Evitar duplicação de tarefas
- Persistência no **localStorage**
- Exibir descrição completa em um modal
- Fechar modal com `ESC` ou clique externo

## Como usar
1. Clone o repositório:
```
git clone https://github.com/seu-usuario/taskFy.git
```

2. Abra o arquivo index.html no navegador.
